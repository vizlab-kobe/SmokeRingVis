# CameraOptimalPathSearch

This program searches an optimal camera path from the outputs generated by
`CameraFocusMulti` and `CameraPathMulti`.

## Placement

Recommended location in the repository:

```sh
SmokeRingVis/Tools/CameraOptimalPathSearch/
```

The tool is independent from the `App/InSituVis*` application directories.
Since `kvsmake -G` uses the current directory name as the target name, the
directory should be named `CameraOptimalPathSearch` when the expected binary
name is `CameraOptimalPathSearch`.

## Build

```sh
./make.sh
```

`kvsmake.conf` sets `KVS_CPP_STANDARD := 17`, and `kvsmake` performs the build.

## Examples

When this tool is placed at `SmokeRingVis/Tools/CameraOptimalPathSearch`:

```sh
./CameraOptimalPathSearch \
    -base-dir ../../App/InSituVis.mpi.CameraFocusMulti \
    -candidate-num 5 \
    -first-file 0 \
    -entropy-ratio 1 \
    -focus-path-ratio 1 \
    -camera-path-ratio 1
```

```sh
./CameraOptimalPathSearch \
    -base-dir ../../App/InSituVis.mpi.CameraPathMulti \
    -candidate-num 9 \
    -first-file 0 \
    -entropy-ratio 1 \
    -focus-path-ratio 1 \
    -camera-path-ratio 1
```

`-candidate-num` can be omitted when it can be inferred from contiguous
`preFocusPath*` columns in `Output/output_video_params.csv`.

The selected images and route images are copied to:

```sh
<base-dir>/ex_Output/Output/
```

## Behavior

The entropy rule is unified as:

```cpp
entropy_cost = 1.0f / max(entropy, epsilon);
```

This means larger entropy is preferred because it becomes a smaller graph cost.
There is no focus/path mode switch for entropy.

The filename parser accepts both existing filename shapes:

```text
output_<time>_<candidate>_<zoom>_<route>.bmp
output_<time>_<candidate>_<zoom>_<route>_<extra>.bmp
```

The fifth numeric token is always treated as the route number.
